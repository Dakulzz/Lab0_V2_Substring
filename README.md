# Вариант 2. Подстрока без повторов

Порядок сдачи — в `ИНСТРУКЦИЯ.md`. Ниже — что должна делать программа.

Файл `data.yaml` содержит набор строк. Для каждой строки нужно найти самую длинную непрерывную подстроку, в которой все символы разные. Если таких несколько — взять **левую**.

Программа выводит найденную подстроку, её длину, индексы начала и конца включительно (нумерация с нуля). Пустая строка: длина 0, позиции пустые. В самом конце выводится случай с самой длинной подстрокой (при равенстве — с меньшим номером).

Алгоритм — скользящее окно: правая граница идёт по строке, левая сдвигается, когда символ уже встречался внутри окна.

## Примеры

Вход:

```yaml
cases:
  - "abcabcbb"
  - "pwwkew"
  - "dvdf"
```

Ожидаемый вывод:

```text
|   line | source   | substring   |   length |   start |   end |
|--------|----------|-------------|----------|---------|-------|
|      1 | abcabcbb | abc         |        3 |       0 |     2 |
|      2 | pwwkew   | wke         |        3 |       2 |     4 |
|      3 | dvdf     | vdf         |        3 |       1 |     3 |

Best case: 1, substring = abc, length = 3
```


## На что обратить внимание

- Если скрипт падает при запуске — изучаем сообщение об ошибке и traceback.
- Если вывод оказался неправильным — запускаем программу в пошаговом режиме и проверяем позицию окна
- Убедитесь, что для всех строк файла скрипт работает правильно
